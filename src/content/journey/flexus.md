CAP application developer and technical product manager for the Intralogistics Hybrid
Fleet Manager, an application recognised with the international **SAP Innovation Award**.

I owned the backend architecture in SAP CAP, the data models and query APIs across SAP
HANA and PostgreSQL, and the algorithmic logic for fleet routing and optimisation. On the
front end I owned the fleet management cockpit, which is the screen users actually live in,
and the surrounding SAP UI5 interfaces.

As technical product manager I owned that cockpit's roadmap and its user experience, which
meant the decisions about what the primary interface of an award-winning enterprise
application should be were mine to make and to defend.

Alongside it ran **TwInTraSys**, a digital-twin research project for internal transport
systems, where I built the Python pipelines that preprocessed customer data and the storage
structure that kept it consistent.
